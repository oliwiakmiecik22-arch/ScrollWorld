# THE SIP — AI-Assisted Production Workflow

THE SIP used AI as a production collaborator while keeping creative direction, selection, and final approval with the student. The finished result is not an autonomous one-prompt output.

## Magnific + Seedance 2.5

Magnific was the visual-generation environment and Seedance 2.5 was the selected video model for the approved moving worlds.

Responsibilities included:

- generating surreal cocktail environments;
- extending camera and world movement;
- supporting first/end-frame continuity where used;
- creating the portal approach and cocktail transitions;
- producing the approved replacement woman/laser sequence.

The repository does not include verifiable Magnific MCP connection data or job logs. The workflow is therefore documented as a creator-operated generation and review process, not as automated MCP generation.

## Codex

Codex supported implementation and technical production:

- React/Vite structure and GSAP ScrollTrigger integration;
- the scroll-position-to-video-time controller;
- requestAnimationFrame smoothing and reverse-scroll behavior;
- chapter timestamp mapping;
- ffmpeg-oriented assembly and short-GOP encoding workflow;
- navigation, cocktail HUD, History, Recipe, and ending interactions;
- accessibility and responsive behavior;
- build, browser, console, asset, and media-integrity checks;
- submission documentation and Git preparation.

Codex did not make the final creative approvals for generated clips and did not replace the approved video worlds with generated code scenery.

## Human / Creative Director

The student remained responsible for:

- the THE SIP concept and core message;
- cocktail order and emotional concepts;
- visual direction and prompt decisions;
- choosing Magnific and Seedance 2.5;
- selecting, approving, or rejecting generated clips;
- approving the portal intro and Mai Tai replacement;
- deciding where navigation and information controls belong;
- deciding that History and Recipe should open only on demand;
- approving the final master and scroll behavior;
- final quality control and submission decisions.

## Decision loop

The production loop was:

```text
human concept and direction
→ AI-assisted visual or technical production
→ inspection against the intended journey
→ human approval / rejection / correction
→ implementation and verification
```

The approved Magnific master remained authoritative throughout. Technical work could improve delivery, seeking, accessibility, and interface clarity, but it could not silently redefine the visual worlds.
